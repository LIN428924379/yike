# 打包成安卓 App —— 手把手步骤

目标：把 [../focus/index.html](../focus/index.html) 这个网页，变成一个**能装到安卓手机上、有图标、点开就用的 App**。

**好消息**：界面和逻辑一行都不用重写。`www/index.html` 就是那个 App 的全部界面。

---

## 第 0 步：先知道你电脑上缺什么

| 需要的东西 | 你现在 |
| --- | --- |
| Node.js | ❌ 没装 |
| JDK 17 | ❌ 没装（`JAVA_HOME` 指向一个不存在的路径，是残留的） |
| Android Studio | ❌ 没装 |
| 磁盘空间 | ✅ 充足（C 盘 ~100 GB、D 盘 ~267 GB 可用） |

三样加起来**大约 8~10 GB 下载**，第一次弄**大概 1~2 小时**（绝大部分时间是在等下载）。

---

## 第 1 步：装三样东西

### ① Node.js
1. 打开 https://nodejs.org
2. 下载 **LTS 版**（左边那个按钮）
3. 双击安装，一路「下一步」，不用改任何选项

### ② JDK 17 ⚠️ 版本要对

1. 打开 https://adoptium.net
2. 选 **Temurin 17 (LTS)** → **Windows** → **x64** → 下载 `.msi`
3. 双击安装。**安装界面上有个选项叫 `Set JAVA_HOME variable`，一定要选上**（选 "Will be installed on local hard drive"）
4. 装完后检查：

```powershell
java -version
```

出现 `openjdk version "17.x.x"` 就对了。

> **如果它显示的还是旧的 8**，说明你电脑上那个残留的 `JAVA_HOME` 没被改掉。手动改一下：
> 「此电脑」右键 → 属性 → 高级系统设置 → 环境变量 → 把 `JAVA_HOME` 的值改成新装的 JDK 17 目录（例如 `C:\Program Files\Eclipse Adoptium\jdk-17.x.x-hotspot`）。

### ③ Android Studio

1. 打开 https://developer.android.com/studio
2. 下载安装（这个包很大）
3. **第一次打开时**它会引导你装 **Android SDK**，选 **Standard** 一路下一步
   （这一步又要下载几个 G，耐心等）

---

## 第 2 步：生成安卓工程

装完上面三样，打开 **PowerShell**，一条条执行：

```powershell
cd D:\Development\Project\DSH-TEST\android-app

npm install @capacitor/core @capacitor/cli @capacitor/android

npx cap init "番茄专注" com.tomato.focus --web-dir=www

npx cap add android

npx cap sync
```

> `com.tomato.focus` 是 App 的「身份证号」，**第一次装到手机上之后就别改了**——改了等于换了一个 App，手机里的数据不通用。

---

## 第 3 步：把图标和启动图装上

工程里已经准备好了 `assets/icon.png`（1024×1024）和 `assets/splash.png`（2732×2732）：

```powershell
npm install --save-dev @capacitor/assets

npx @capacitor/assets generate --android
```

---

## 第 4 步：打包出 APK

**方法 A（图形界面，推荐新手）**

```powershell
npx cap open android
```

Android Studio 打开后：菜单 **Build → Build App Bundle(s) / APK(s) → Build APK(s)**，等几分钟，右下角会弹一个小提示，点里面的 **locate** 就能找到文件。

**方法 B（命令行，更快）**

```powershell
cd android
.\gradlew assembleDebug
```

产物都在这个位置：

```
android\app\build\outputs\apk\debug\app-debug.apk
```

---

## 第 5 步：装到手机上

1. 把 `app-debug.apk` 传到手机（数据线、微信「文件传输助手」、网盘都行）
2. 手机上点开这个文件
3. 系统会提示「未知来源应用」，**允许一次**
4. 安装完成，桌面出现橙色计时器图标 ✅

---

## 以后改了代码怎么办

```powershell
# 1) 把网页版的最新版本复制过来
Copy-Item D:\Development\Project\DSH-TEST\focus\index.html D:\Development\Project\DSH-TEST\android-app\www\index.html -Force

# 2) 同步进安卓工程
cd D:\Development\Project\DSH-TEST\android-app
npx cap sync

# 3) 重新打包
cd android
.\gradlew assembleDebug
```

熟练之后**两分钟就能出一个新 APK**。

---

## ⚠️ 一个已知问题（等第一个 APK 成功之后再解决）

**App 里那个「桌面通知」开关暂时不管用。**

原因：现在用的是网页的通知接口，在安卓的 WebView 里不可靠。要让**锁屏时也能响**，需要加一个原生插件：

```
@capacitor/local-notifications
```

这个等你的第一个 APK 装上手机、确认能用之后，我再带你加。**先把东西装到手机上，比什么都重要。**

---

## 打包完你会得到什么

| | 网页版 | 打包后的 App |
| --- | --- | --- |
| 打开方式 | 浏览器、有地址栏 | 点桌面图标，全屏 |
| 锁屏提醒 | 不可靠 | 能（加了插件之后） |
| 发给朋友 | 得给网址 | **直接发安装包** |
| 联网 | 不需要 | 不需要 |
| 数据 | 存在浏览器里 | 存在 App 里（卸载会丢） |
